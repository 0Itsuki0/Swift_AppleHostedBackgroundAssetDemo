#  Swift: Apple Managed Background Asset Demo


This demo includes
- App side implementation for downloading/removing asset packs, monitoring download progress, as well as get asset pack contents.
- [A sample Asset pack](./MyAssetPack/) to be used for testing.


For more details, please refer to my blog [Swift: Integrate Apple Hosted (Managed) Background Assets](https://medium.com/@itsuki.enjoy/swift-integrate-apple-hosted-managed-background-assets-7867175cbe98)


https://github.com/user-attachments/assets/7fcf219e-1503-4a55-b00d-8dd39d0e5dc4



## Run the Demo

- Go into the [MyAssetPack](./MyAssetPack/) Folder
- Archive the asset pack with command `xcrun ba-package Manifest.json -o asset.aar`
- Upload to app store connect, or serve it locally with `crun ba-serve --host localhost asset.aar` and `xcrun ba-serve url-override https://localhost:<port_above>`
- Set up app group: same app group for the downloader extension, main app, and the `BAAppGroupID` key of the main app's [Info.plist]().
- Run the app


## Asset pack structure Recommendation

```
AssetRootFolder
├── Manifest.json
├── src
│   └── ...other asset files.
└── tree.json
```

- `src`: folder contains all asset files
- `tree.json`: folder structure generated by the `tree` command: `tree src -J > tree.json`

**Reason:**
We don't have any APIs for getting *what contents are available at what path*.
This structure allow us to get contents within the `src` folder without having to hard code all file paths.
